# Current visitor flow

1. Enter: cinematic conceptual hill landscape, subtle atmospheric movement and scroll-driven zoom (static under reduced-motion preference).
2. Packages: one active floating tile; faded previous/next tiles behind; side arrow buttons, horizontal swipe and keyboard controls. Book this package selects the route and scrolls to vehicles.
3. Vehicles: same layered tile system. Select a vehicle, then follow the scroll prompt to review the booking request.
4. Review: compact versions of both selected tiles retain the package photo and matching representative vehicle image. Change buttons open native dialogs without losing form entries.
5. Route: enter pickup and destination; package stops start selected, can be deselected, and other places can be added. Choices are retained per package while the page remains open.
6. Quote: name, travellers and fixed/flexible date plus optional requests are composed into a WhatsApp draft with only the selected stops. Human agreement confirms availability, route, fare and booking. No payment or automatic reservation is made by this frontend.
